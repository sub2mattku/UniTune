# ⚡ UniTune

### Universal Electric Light Vehicle Tuning

**UniTune** is an ESP32-based tuning project designed to bring more customization and control to electric light vehicles, including e-scooters, e-bikes, hoverboards, and more.

The main target is the **Xiaomi Electric Scooter 4 Lite Gen 2**, with the goal of going beyond the limitations of the original Xiaomi Home app and providing a more customizable riding experience through a web-based dashboard.

## 🚀 Features & Goals

- 🌐 **Web Dashboard** — A browser-based interface for accessing tuning options and vehicle information.
- ⚡ **Performance Tuning** — Explore configurable performance parameters and speed limits where supported.
- 🏁 **Zero-Start Mode** — Investigate enabling motor operation without the usual kick-start requirement, where supported.
- 🎮 **Torque Customization** — Aim for more direct throttle response and a more responsive riding experience.
- 🔌 **ESP32 Powered** — Designed around the 30-pin ESP32-D-WROOM development board.
- 🛴 **Multi-Vehicle Vision** — Built with the long-term goal of supporting different types of electric light vehicles.
- 💸 **Affordable & Accessible** — Focused on affordable hardware and accessible software rather than expensive proprietary tuning solutions.

## 🎯 Primary Target

**Xiaomi Electric Scooter 4 Lite Gen 2**

UniTune aims to offer more control over the riding experience than the stock Xiaomi Home app, with a focus on customization, responsiveness, and a convenient web interface.

The project is under development, and compatibility depends on the scooter's controller, firmware, and communication interfaces.

## 🧰 Hardware

| Component | Purpose |
|---|---|

Additional hardware may be required depending on the vehicle and controller.

## 🖥️ Web Dashboard

The goal is to provide a simple, accessible dashboard that works through a web browser, without relying entirely on the manufacturer's mobile application.

Planned functionality may include:

- Vehicle status and information
- Supported tuning parameters
- Performance configuration
- Connection and diagnostic information

The final interface and supported features may change as development progresses.

## 🛠️ Project Status

**UniTune is currently a work in progress.**

Features, supported vehicles, hardware requirements, and tuning capabilities are still being developed and tested. Not every feature listed above is currently implemented or confirmed to work.
